# Magma Installation and Polyfunctions Generation

Magma is required only for regenerating the `Bootstrapping_Polyfunctions`
digit-extraction polynomial files.  It is a licensed CAS, so this repository
does not contain the binary or license file.

## Required Official Files

Put these files under:

```text
tools/magma_downloads/
```

Expected names:

```text
magma.avx2.exe.gz
shared_complete.tar.gz
magmapassfile
```

This machine is `x86_64` and supports AVX2, so `magma.avx2.exe.gz` is the
right executable variant.  If the downloaded executable has another name, set
`MAGMA_EXEC_NAME` or `MAGMA_EXEC_GZ`.

The official download server requires Basic authentication.  If local files are
not present, the installer can download them when these variables are set:

```bash
export MAGMA_DOWNLOAD_USER='...'
export MAGMA_DOWNLOAD_PASS='...'
```

Do not commit those credentials.

## Install

```bash
cd /home/user/order4-artifact
bash scripts/install_magma_local.sh
```

The installer writes:

```text
tools/magma/
tools/bin/magma
```

It does not modify the baseline repositories.

## Generate Bootstrapping_Polyfunctions Files

```bash
cd /home/user/order4-artifact
bash scripts/run_polyfunctions_magma_generation.sh
```

Generated files are written to an isolated workdir:

```text
results/polyfunctions_magma_generation/HElib/
```

The log is:

```text
results/baseline_matrix/polyfunctions_magma_generation.log
```

This wrapper intentionally avoids writing into
`baselines/Bootstrapping_Polyfunctions`.  After generation, the files can be
copied into that tree only if we explicitly want to rebuild that baseline.

## Scope Note

`Scripts/Find_digit_poly.m` regenerates the Polyfunctions/GIKV digit polynomial
tables hardcoded in that baseline, with primes `[2, 3, 5, 17, 127]` and
`e_inner` values `[1, 5, 6, 16]`.  This is not the same object as our
`p=65537, B=17` bounded-support cleaner; the latter is generated by our Python
exact-cleaner search and exported under:

```text
docs/cleaner_polynomial_forms_p65537_B17.json
docs/cleaner_polynomial_forms_p65537_B17.tex
```
