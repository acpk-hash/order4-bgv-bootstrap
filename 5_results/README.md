## Log format

Every bootstrapping log is the unedited console output of one run (the
measurement host's home directory is replaced by `<HOST>`). The lines that
matter:

```
INFO: total bits = 1066, security level = 92.8902      modulus chain HElib built
log2(aux) = 8.000000                                   auxiliary radix A = 2^8 = 256
HELIB_AUX_ORDER4_EVAL enabled: deg(P)=727, ...         evaluator ON (absent: OFF)
time for linear1 = .., linear2 = .., extract = .., total = ..   one line per trial, then the mean
### bts finished, everything ok ###                     every slot decrypted correctly
Maximum resident set size (kbytes): ...                peak memory (GNU time)
```

`3_experiments/make_tables.py` turns a directory of such logs into the paper's
tables, and `3_experiments/compare_report.py` into the control-group report.
