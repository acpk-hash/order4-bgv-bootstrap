  Order-Four Character Filter: Applicability Analysis
================================================================

CONDITION: The order-4 filter requires:
  1. p ≡ 1 (mod 4)  →  A with A² ≡ -1 (mod p) exists
  2. (A+1)·B < p/2  →  A is B-injective on the bounded support

PARAMETER ANALYSIS:

  Prime p     A (A²=-1)   Max B    Typical B   Applicable?
  -------     ---------   -----    ---------   -----------
  17          4           1        ~3          NO (B too large for p)
  127         N/A         N/A      N/A         NO (p≡3 mod 4)
  257         16          7        ~5          MARGINAL
  8191        N/A         N/A      N/A         NO (p≡3 mod 4)
  65537       256         127      17          YES ✓ (main result)
  786433      100025      ~3900    ~17         YES ✓

KEY INSIGHT:
  The order-4 optimization is designed for LARGE plaintext primes
  (p >> B²), which is exactly the regime where bootstrapping is
  most expensive and optimization is most needed.

  For p=65537 (the standard large-prime HElib parameter):
    A = 256, B = 17, (A+1)·B = 4369 < 32768 = p/2  ✓
    Speedup: 49.8% on digit extraction, 38.4% on total bootstrap
