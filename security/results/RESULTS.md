# Measured results

Generated by `make_results.py` from the JSONL files in this directory. Every
figure is a measurement; anything derived says so. Raw console output is in
`../raw/`.

Tools: the stock Lattice Estimator at commit `3e48ef4`, and the rotated
primal hybrid of ePrint 2026/279 from `github.com/TabOg/mlwe-hybrids`
(`PrimalHybrid`) with its `lattice_estimator` submodule advanced to the same
commit, so both columns rest on one lattice-estimation codebase. Cost model
`RC.MATZOV`, `sigma = 3.2`, sparse ternary secrets, `m = n` samples.

Ring `m = 2^16`, main key weight 120, encapsulated weight 26, three
trials, single threaded. `OFF` is the bounded-support evaluator, `ON` the
order-four evaluator; the pipeline is otherwise identical and the

shorter chain while the order-four evaluator gets faster, because
digit-extraction cost is an operation count fixed by `(p, A, B)`
multiplied by a per-operation cost that the number of residue limbs sets.


## 2. Whole bootstrapping, by stage

Shown for `p = 65537`, the least favourable case for a total ratio: it has
the most slots, so the linear transforms, which the contribution does not
touch, dominate.

| stage | OFF (s) | ON (s) | ratio |
|---|---:|---:|---:|
| bootstrapping key switch | 9.50 | 9.58 | 0.99 |
| coefficients to slots | 9.11 | 9.13 | 1.00 |
| digit extraction | 20.06 | 10.81 | 1.85 |
| slots to coefficients | 3.56 | 3.61 | 0.99 |
| total recryption | 42.34 | 33.25 | 1.27 |

The three stages the method does not touch move by 0.99 to 1.00, which is
the measurement confirming it is confined where we claim. Capacity
remaining is 344.5 bits for OFF and 319.4 for ON, so on the throughput
basis used by the prior work, remaining capacity divided by total time,
the gain is 1.23x against 1.27x on wall clock alone.

The correct post-attack figure for an instance is the minimum over every
attack run, not the stock figure minus a delta: the stock minimum is often
already cheaper than the rotated tool's own plain hybrid, and on two
instances the rotated cost is higher than the plain one, so a delta would be
negative.
